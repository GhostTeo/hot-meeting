# Hot Meeting

Web app per ordinazioni e gestione operativa della pizzeria Hot Meeting (Milano, Piola).

## Aree

- Cliente: menu, personalizzazioni, carrello e checkout.
- Creator: servizio, ordini, menu e report.
- Cucina: comande operative con timer e stato pronto.

La prima versione usa il salvataggio locale del browser. Backend, pagamenti e notifiche reali verranno collegati in fasi successive.

## Avvio locale

```bash
python3 -m http.server 4173
```

Aprire `http://localhost:4173`.

## Test

```bash
npm test
```
